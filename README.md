# Mr. White 🎩

Versión en español del juego de deducción social Mr. White / Undercover, para jugar offline en un solo celular.

- Civiles, Undercover y Mr. White configurables
- 312 pares de palabras: modo General y modo 🇨🇴 Colombiano (groserías opcionales)
- Orden de pistas al azar (Mr. White nunca empieza), votación, adivinanza de Mr. White y puntajes

Las palabras están en `app/src/main/assets/palabras.json`.

El APK se compila con GitHub Actions y se publica en Releases.
